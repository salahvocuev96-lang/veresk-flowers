# Вереск — сайт цветочного ателье (демо)

Многостраничный интернет-магазин цветов на чистом HTML/CSS/JS — без сборки и зависимостей.

## Как открыть
Самый простой способ — открыть `index.html` двойным кликом в браузере.
Лучше — через локальный сервер (корректнее работают пути):

```bash
cd veresk && python3 -m http.server 8000
```
и открыть http://localhost:8000

## Страницы
`index.html` главная · `catalog.html` каталог (фильтры, сортировка, поиск `?q=`) · `product.html?id=N` товар · `cart.html` корзина и оформление · `favorites.html` · `about.html` · `delivery.html` · `contacts.html` · `reviews.html` · `faq.html`

## Структура
- `assets/css/tokens.css` — дизайн-токены (менять цвета/шрифты здесь)
- `assets/css/styles.css` — компоненты и адаптив
- `assets/js/data.js` — **товары, категории, отзывы, FAQ, контакты** (редактировать контент здесь)
- `assets/js/app.js` — шапка, подвал, корзина, избранное, поиск
- `assets/js/pages.js` — логика страниц
- `assets/img/` — фото (WebP), `assets/fonts/` — шрифты

## Ограничения демо
- Оплата и отправка форм не подключены: заказы, отзывы, корзина хранятся в браузере (localStorage).
- Контакты, цены, отзывы, история бренда — вымышленные.
- Фото — Unsplash, перед запуском заменить на собственные.
